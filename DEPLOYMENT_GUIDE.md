## ☁️ 2. Free Permanent 24/7 Cloud Deployment (Render.com)
If you want to host it permanently in the cloud without keeping your computer running:

1. Push this folder to your **GitHub** account.
2. Sign in to [https://render.com](https://render.com).
3. Click **New +** ➔ **Web Service** and choose your repository.
4. Render automatically reads `render.yaml`:
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
5. Click **Deploy Web Service** to get a permanent `https://your-app.onrender.com` domain.
